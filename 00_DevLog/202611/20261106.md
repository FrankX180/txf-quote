# 2026-11-06

## 富台來源鏈實測與凌晨延遲收斂（13:50）

### 問題現象
台指期休市、富台仍有成交時，站上能否取得即時富台價。逐家實測免費源（HiStock／TradingView／Yahoo／鉅亨／玩股網）與三家券商 API（富邦／元大／永豐）。

### 根因／決策理由
SGX 富台的即時報價有授權限制，免費源不是延遲就是跨午夜斷線：HiStock 分時在 23:59:46 凍結、TradingView 固定延遲 10 分、Yahoo 沒有這檔商品、玩股網延遲僅 4~5 分但只放行住宅 IP（Worker 400、Actions 403）。富邦 Neo API 的商品清單只認 TAIFEX；永豐 Shioaji 有 TWN 合約但本帳號缺 SGX 報價簽署，snapshot 回 0。因此維持 HiStock（白天）＋TradingView（全天候）的組合，並把延遲直接標在畫面上，不假裝即時。
