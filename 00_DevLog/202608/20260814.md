## 流量計數器（v0104，免第三方）

### 需求
同時在線、今日瀏覽／訪客、今日峰值；免費、可分析、不另開 GA。

### 方案
沿用既有 Cloudflare Worker + D1（`txf-imb`），不另接 Umami／Plausible／GA。

| 指標 | 定義 |
|------|------|
| 在線 | `presence` 最近 90 秒有心跳 |
| 今日 PV | 開頁 `hit=1` 計 1 次 |
| 今日 UV | 同日不同 `sid`（localStorage） |
| 峰值 | 當日 `online` 最大值 |

| 層 | 內容 |
|----|------|
| Worker | `?kind=ping&sid=&hit=`、`?kind=stats`；表 `presence` / `traffic_day` / `traffic_sid` |
| 前端 | 頁底顯示；開頁 hit + 每 30 秒心跳 |
| 日鍵 | 與報價相同 `tradingDayKey`（台指交易日） |

- `?kind=stats` → `ok:true, online,pv,uv,peak,windowSec:90`
