# 2026-08-17 夜盤走勢圖空白修復（barWallTs 誤平移）

## 問題現象（老公回報）
- 當日（夜盤）走勢圖：主折線畫不出來，只看到一條橘色水平線（36MA）。
- 兩日折線圖看起來正常。

## 根因
`index.html` 的 `barWallTs()`（夜盤棒時間戳還原）用 `prevTradingYmd()` 算 gapDays 判斷「跨周末的周五夜盤」：

- 週五夜盤：奇摩把棒標到下一交易日（date=20260816，週日），需平移 -2 天還原為 8/14 15:00 起。
- 週一～四夜盤：奇摩 ts 已是牆鐘、date=開盤曆日，**不該平移**。

但 `prevTradingYmd(20260817)` 會跳過週末回到 8/14，gapDays=3 被誤判為跨周末 → 週一（8/17）夜盤整批棒被平移 -3 天到 8/14。

### 連鎖效應（當日模式）
1. 8/17 夜盤棒全部平移到 8/14 15:00-18:00。
2. 尾端 live 點（牆鐘 8/17 18:37）接在後面 → `sessRange` 的 t0 變成 8/17 15:00。
3. 8/14 的棒全部落在圖外（x 負值）→ 折線 runs 全空 → 主折線不畫。
4. 36MA 是逐點畫的（不受 runs 影響）→ 只剩尾端一小段在圖內 → 看起來像橘色水平線。

### 2 日模式
同樣錯位（週五夜被畫在 8/12、週一夜被畫在 8/14），但每段 ≥2 點所以折線畫得出，老公沒注意到時間軸錯位。

## 修法
`barWallTs()` 改以 **date 欄位的星期** 判斷：date 落在週六/週日 → 週五夜盤 → 才平移還原；週一～四 → 直接回傳（不平移）。

## 驗證
- Node 重現測試：修前週一夜盤 8/17 15:01 → 8/14 15:01（錯）；修後保持 8/17 15:01 ✓；週五夜盤仍正確還原 8/14 15:01 ✓。
- 端到端模擬（GitHub 最新資料）：當日模式 217 點全在圖內、折線 1 段；2 日模式 3 段時間軸正確（週五夜 8/14 → 週一日 8/17 → 週一夜 8/17）。
- `node --check` 語法通過。
- Pages 已更新（版本 1.23），新 barWallTs 上線。
