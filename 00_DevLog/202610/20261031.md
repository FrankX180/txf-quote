## 夜盤段拆帳修正與 CI actions 升級（11:36）

### 問題現象
台指期看盤站「法人未平倉」表最上列停在昨日，夜盤段與日盤段相加不等於合計（16:43 反映「怎麼還在10月29日」）；晚間另收到 GitHub Actions 失敗通知，需判斷是否為程式問題。

### 根因／決策理由
夜盤列三層錯：①when.want_uncovered 15:30 後直接回 False，整支 fetch_uncovered.py 不執行，夜盤時段 15:00→隔日05:00 頁面永不更新；②fetch_latest_night 固定從 day8-1 起算，永遠跳過當天那場；③前端夜盤列沒帶 _prevClose，表格自動取下一列（隔天日盤），漲跌方向相反。更根本的是「夜盤屬於哪個交易日」搞反：10/29 15:00 起的夜盤屬 10/30 交易日，該標 10/30(夜) 並與 10/30 日盤段相加等於合計，先前卻塞進屬 10/31 的當晚夜盤，拆帳因此對不上。CI 失敗則是 GitHub runner 未分配（fetch job 卡 queued 從未啟動），非程式錯誤。
