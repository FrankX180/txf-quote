## 日盤收盤後五檔被 Yahoo 退化書清空 — 根因與修復（升版 2.24）

### 症狀

## 法人未平倉數據異常（09/11）修復

### 症狀

1. 日盤 09/11 法人未平倉特法與三大法人數據錯亂，09/11 外資/投信/自營/散戶水位全為 0.0，導致當日 Δ 變成全額跳動（外資 +82,850、投信 -74,450、散戶 -10,300）。
2. 十大與特法數值為 `null`，且歷史 `*Delta`（投信、自營）未在 `fetch_uncovered.py` 中完整計算。

### 根因

1. 14:41 爬蟲執行時，期交所官網 `futContractsDateDown` 尚未釋出 09/11 資料，解析產生 0 值假列。
2. `when.py` 中的 `day_chips_ready` 判定僅檢查 `instProds` 與時間，未能防禦 0 值假資料，導致 15:00 定案鎖死，不再重新抓取已上架的正式官網資料。
3. `fetch_uncovered.py` 在計算歷史差額時漏填 `trustDelta` 與 `dealerDelta`。

### 修正

1. `scripts/when.py`：`day_chips_ready` 增加非全 0 護欄，若三大法人水位皆為 0 則判定為未定案，允許持續重抓。
2. `scripts/fetch_uncovered.py`：補齊 `trustDelta` 與 `dealerDelta` 計算。
3. `data/uncovered.json`：重新抓取期交所 09/11 正式數據，三大法人、散戶、十大與特法未平倉數據完整恢復。
