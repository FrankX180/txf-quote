# 富台（SGX TWN）即時報價來源調查

> 2026-11-06 實測。目的：台灣期貨休市時，站上要能用富台成交價換算台指點數。
> 結論一句話：**免費源拿不到 24 小時即時；四家券商／資料源只有永豐「差一份 SGX 報價簽署」。**

## 站上目前怎麼做

- 休市模式：`台指期(估) ＝ 富台現價 × 倍數`，倍數＝同時刻的台指 ÷ 富台（1 分 K 配對）
- 富台現價取「時間戳較新」的那個：
  - HiStock 分時 `histock.tw/stock/module/stockdata.aspx?no=TWN`（Worker `?kind=twn` 代理）
  - TradingView 1 分 K 存檔（`scripts/fetch_twn_hist.py` → `data/twn-hist.json`）
- 前端 3.66 起在富台現價旁顯示「N 分前」，超過 15 分轉琥珀色

## 各來源實測結果

| 來源 | 商品 | 即時性 | 判定 |
|---|---|---|---|
| HiStock 分時 | 有 | 約 30 秒一點 | 可用，但**跨午夜 23:59:46 後整條凍結**（價格重複同值、或變 0），凌晨失效 |
| TradingView（免登入 ws） | 有 | 延遲約 10 分 | 全天候可用，慢 |
| Yahoo | 無 | — | `TWN=F`／`STW=F`／`^TWN` 全 404 |
| 鉅亨 cnyes | 有頁面 | 不明 | API 要授權符號，`TWNCON:GF` 等四種寫法全被擋（mType is null） |
| 玩股網 wantgoo | 有 | **約 4~5 分（實測）** | 端點抓到、本機可讀；但只限住宅 IP。Worker `400`、GitHub Actions `403`，機房網段被 WAF 擋。2026-11-06 老公決定不用 |
| 富邦 Neo API | **沒有** | — | `futopt.intraday.products(type="FUTURE")` 150KB 清單無 twn/sgx/富台；`exchange="SGX"` 直接回 `exchange must be one of the following values: TAIFEX` |
| 元大 API | 未驗 | — | 只有國內期貨報價 OCX（`ocx\quote\YuantaQuote.ocx`）；19876 下單／19877 推播都在跑，但沒有海期元件，且需 Windows 常駐 |
| 永豐 Shioaji | **有合約** | 待開通 | 合約清單有 `TWN`（名稱「富時指11」，2026/11，參考價 3,712.25）；`snapshot` 回 `close=0, vol=0`；同一支 API 抓 `TXF` 正常（39,240／77,408 口） |

## 關鍵結論（永豐這條）

- Shioaji 官方支援 Linux，且**行情不需要 CA 憑證**（只有下單要 `activate_ca`）→ 可以上雲
- 卡點在「線上簽署中心 → 期貨類」只有**國外期貨 CME 報價簽署**（已簽），沒有 SGX 那一項
- 要跟營業員申請：`國外期貨 SGX 報價簽署`，用途＝Shioaji API 抓 SGX 富台（TWN）
- 開通後驗收方式：`api.snapshots([TWN合約])` 的 `close` 不是 0 且 `total_volume` 會動

## 開通後要做的事

1. `TWN` 群組有 14 檔代碼（TWND7、TWNA7、TWNE7…），先用 snapshot 找出有量的是哪一檔
2. 寫一支抓取器（GitHub Actions 定時或常駐），把富台即時價推 Cloudflare（D1/KV），前端加一條「雲端有 N 秒內的價就直接用」
3. 順手對帳：永豐參考價 3,712.25 vs HiStock 3,384.5，兩者差約 9%，不可能同時對，要用同一時刻三邊（永豐／HiStock／TradingView）對一次並重算倍數

## 玩股網拆解結果（2026-11-06，最後不採用）

- 商品 id 就是 `stwn&`，頁面路由 `/global/stwn&`
- 目錄：`/investrue/all-alive`（6,654 檔，富台標 `type=Futures`、`country=SINGAPORE`、`fintune=false`）
- 可用端點：`/global/stwn&/historical-realtimeprice-pricemin1-tradedate?tradeDate=<當日 00:00 ms>`
- 會回 400 的端點：`/info`、`/realtimeprice-pricemin1`、`/daily-candlesticks`
- 實測 02:26 抓到 707 根、最後一根 02:22 → 延遲 4.5 分，跨午夜仍有資料
- 但同一支 API 只有住宅 IP（本機）是 200；Cloudflare Worker 400、GitHub Actions 403
- 結論：要用只能靠本機常駐推送，違反「雲端自足」；老公 2026-11-06 決定不用，維持現行 HiStock＋TradingView
