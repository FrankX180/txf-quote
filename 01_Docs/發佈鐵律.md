## 硬規則

改 `index.html`／`worker/yahoo-quote.js` 且要讓線上生效時，**同一輪必須做完這三件事**，禁止只改本機就回報「修好了」：

1. **升版本**  
   - 頁腳 `.ver`  
   - `purgeOldMinCache` 的 `VER`（兩處必須同號）  
   - 小改動：`2.11` → `2.12`（第三碼 +1）  
   - 升 VER 會清 `txfMin`／`txf1m`，這是故意的。

2. **commit + push `origin/master`**  
   - **正式站（2026-11-23 起）：`https://txf.blok.trading/` 由 Cloudflare Workers Static Assets（worker `txf-site`）供應**，資料有變更時由 `update-quote.yml` 自動 `build_site.py` + `deploy_site.py`。  
   - 舊網址 `https://frankx180.github.io/txf-quote/` 只是 GitHub Pages 的 301 入口，**不再是正式站**。  
   - 遠端常有 Actions 行情快照：不要跟 `data/*.json` 一起 rebase 打架；前端／Worker 用 cherry-pick 接到最新 `origin/master` 再推。  
   - **沒推上去 = 線上還是舊版。**

3. **改了 Worker 還要 deploy（雲端自動）**  
   push `worker/yahoo-quote.js` 後，`.github/workflows/deploy-worker.yml` 會**雲端自動部署**（repo secret `CLOUDFLARE_API_TOKEN`，scoped token）；等該 workflow 綠燈再回報。  
   只 push JS 不會更新線上。本機可選 `python scripts/deploy_worker.py` 手動補（金鑰讀環境變數或本機 secrets 檔）。
