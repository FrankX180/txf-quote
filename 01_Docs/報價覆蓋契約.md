# 報價覆蓋契約（Quote Overlay Contract）

> **SSOT**：即時報價「哪些欄位由哪個來源提供、以誰為準」的唯一出處。
> **目的**：消除 Worker（JS）與 Actions（PY）兩條路徑各自解釋、語意漂移。
> **鐵律**：任何覆蓋規則變更 → 先改本檔 → 再改兩端 → 跑 `python scripts/verify_overlay_contract.py`（須 CONTRACT OK）。

## 1. 來源角色

| 來源 | 提供的欄位 | 不可取代性 |
|------|------------|------------|
| TAIFEX MIS `getQuoteList`（REST） | 成交價、當盤開高低、參考價、漲跌停、累計量、買一賣一 | 官方當盤值；Yahoo OHLC 是混盤不可信 |
| Yahoo `stockList` | 五檔 orderbook、內外盤 `in/out`、相關商品、`chart` 分鐘 K | **輪詢累計口數的公開源**（無狀態 cron 唯一現成欄位）。重建源＝富邦逐筆（輔、不覆寫 Yahoo）。MIS REST／SockJS 皆無 in/out。 |

MIS 掛 Cloudflare、>10 req 需 proxy（§9.1）；**只當覆蓋層，不當主源**。完整五檔要 SockJS 推流，與「無狀態 cron」不相容，本站不採用。

## 2. 覆蓋後欄位歸屬（真相表）

| snapshot 欄位 | 來源 | 備註 |
|---|---|---|
| `CLastPrice` | MIS | 官方成交價 |
| `COpenPrice` / `CHighPrice` / `CLowPrice` | **MIS（僅盤別相符時）** | MIS 無值或盤別不符 → 由 1 分 K fallback |
| `CCeilPrice` / `CFloorPrice` | MIS | 前端尚未接 |
| `CRefPrice` | MIS | |
| `CDiff` / `CDiffRate` | MIS | |
| `CTotalVolume` | MIS | 單位＝口 |
| `CDate` / `CTime` | MIS | |
| `CBidPrice1..5` / `CAskPrice1..5` / 量 | **Yahoo** | orderbook。來源日≠今日交易鍵 → 不覆蓋當盤書（STALE） |
| `inMarket` / `outMarket` | **Yahoo** | 輪詢累計口數。來源日≠今日交易鍵 → 不寫 D1 imb、snapshot 不把殘值當 live |

## 3. 前端消費路徑（關鍵事實）

- **Worker `GET /`** → `liveRows`（Yahoo stockList 格式）→ 前端 `buildQuote()` **把 OHLC 硬編碼留空** → 再由 `patchQuoteOHLC()` 以 K 線填當盤真值。
- **Pages `data/snapshot.json`** → `snap` → 直接讀 `COpenPrice` 等（MIS 值）。
- ⚠️ **前端不讀 `regularMarketOpen` / `regularMarketDayHigh` / `regularMarketDayLow`** → Worker **不再**把 MIS OHLC 寫進這三欄（2026-10-09 移除無消費者覆蓋）。

## 4. 兩端實作現況

| 項目 | PY `scripts/fetch_quote.py` | Worker `worker/yahoo-quote.js` |
|------|------------------------------|-------------------------------|
| 成交價 / 參考價覆蓋 | ✓ | ✓ |
| OHLC 覆蓋 | ✓ `misOpen→COpenPrice`（**有消費者**） | ✗ 已移除無消費者 `regularMarketOpen/High/Low` |

**自建換算係數（2026-10-09 v2.63，GAS 退為備援）**
